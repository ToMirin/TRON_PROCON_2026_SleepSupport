# ハードウェア・部品・配線

[READMEに戻る](../README.md)

## 用意する部品

以下は本プロジェクトの構成です。接続先はMCUのポート名・ピン番号で表記しています。ボードのコネクタ位置は、使用する基板のピン配置と照合してください。

| 部品 | 数量 | 用途・条件 |
|---|---:|---|
| NUCLEO-H533RE | 1 | STM32H533RE搭載、CPU設定250 MHz。Flash 512 KiB、RAM 272 KiB |
| ICS-43434搭載マイク基板 | 1 | I2Sデジタル音声入力、3.3 V系 |
| I2C接続16文字×2行LCD | 1 | 開発構成はFreenoveの5 V駆動品。ドライバの端子割り当てに対応するもの |
| I2C用双方向レベル変換回路 | 1組 | MCUの3.3 V系とLCDの5 V系を接続 |
| A/B相ロータリーエンコーダ | 1 | 設定値の変更。4カウントを1操作として扱う |
| タクトスイッチ | 1 | 時刻設定で「時」から「分」へ移るためのSW2。設定の確定や測定の開始・停止にはボード搭載のSW1を使用 |
| 砲弾型LED・電流制限抵抗（任意） | 各3 | 状態・異常表示用。開発配線の抵抗は1 kΩ |
| microSDカードスロット変換基板 | 1 | 3.3 VのSPI接続に対応するもの |
| microSDカード | 1 | ソフトウェアはFAT16・FAT32・exFATに対応。使用カード例：KIOXIA EXCERIA 128 GB（KLMEA128G、exFAT） |
| 積層セラミックコンデンサ（0.1 µF） | 2 | マイクとmicroSDカードの電源デカップリング用に各1個 |
| 積層セラミックコンデンサ（10 µF） | 1 | microSDカードの電源デカップリング用 |
| 配線材・ブレッドボード等 | 一式 | 接続と固定 |
| USBデータケーブル・PC | 一式 | ボードへの給電、プログラム書き込み、必要に応じてシリアル確認 |
| microSDカードリーダー | 1 | PCでCSVを確認 |

LCDはI2Cアドレスだけでなく、I2C変換基板からLCDへの端子割り当てもドライバと一致する必要があります。現在の割り当ては `P0=RS`、`P1=RW`、`P2=E`、`P3=バックライト`、`P4～P7=D4～D7` です。ソフトウェアは既定で7 bitアドレス `0x27`、`0x3F` を探索します。

## マイク（I2S2）

| マイク端子 | 接続先 |
|---|---|
| VDD | 3.3 V |
| GND | 共通GND |
| L/R | GND（左チャンネル） |
| WS | PB12 / I2S2_WS |
| SCK | PB13 / I2S2_CK |
| SD（音声出力） | PB14 / I2S2_SDI |

マイクのVDD–GND間に、0.1 µFコンデンサを電源端子の近くに配置します。STM32がクロックを出力し、マイクの音声を受信します。設定は16 kHz、24 bitデータ／32 bitスロット、Philips I2S形式です。MCLKは使用しません。マイクの `SD` は音声信号名で、microSDカードとは別です。

## LCD（I2C1）

| 信号 | MCU側 | 接続 |
|---|---|---|
| SCL | PB6 | レベル変換回路経由でLCDのSCLへ |
| SDA | PB7 | レベル変換回路経由でLCDのSDAへ |
| 電源 | 3.3 V／5 V | 変換回路の低電圧側を3.3 V、高電圧側とLCDを5 Vへ |
| GND | GND | MCU、変換回路、LCDで共通化 |

SCL/SDAには各電圧側のプルアップが必要です。搭載済み抵抗の有無を確認してください。5 V側の信号をMCUへ直接接続しない構成です。

## スイッチ・エンコーダ・LED

| 信号 | MCUピン | 接続・動作 |
|---|---|---|
| SW1 | PC13 | ボード搭載ユーザースイッチ。押下時High |
| SW2 | PC2 | 外付けスイッチでGNDへ接続。内部プルアップ、押下時Low |
| エンコーダA相 | PC6 / TIM8_CH1 | 内部プルアップ |
| エンコーダB相 | PC7 / TIM8_CH2 | 内部プルアップ |
| エンコーダ共通端子 | GND | A/B接点の共通端子 |
| DBG_LED1 | PC10 | 電流制限抵抗とLEDを介してGNDへ |
| DBG_LED2 | PC11 | 同上 |
| DBG_LED3 | PC12 | 同上。システム異常時に点灯 |

エンコーダの機械的な端子位置は製品によって異なります。現在の開発配線では、右回転で値が増えるようにソフトウェアで方向を補正しています。

## microSD（SPI1）

| カード信号 | MCU・電源側 | 役割 |
|---|---|---|
| CD/DAT3 | PC4 / SD_CS | チップ選択 |
| CMD | PA7 / SPI1_MOSI | MCUからカードへのデータ |
| CLK | PA5 / SPI1_SCK | 通信クロック |
| DAT0 | PA6 / SPI1_MISO | カードからMCUへのデータ |
| VDD | 3.3 V | 電源 |
| VSS | GND | グランド |
| DAT1・DAT2 | 未接続 | SPI接続では未使用 |
| 機械式カード検出端子 | 未接続 | 挿入検出には使用していない |

microSDカードのVDD–GND間に、デカップリング用の0.1 µFと10 µFのコンデンサを各1個、並列に接続し、カードスロットの電源端子の近くに配置します。

現在の設定はSPI Mode 0、8 bit、MSB first、250 kHzです。初期化後も同じ通信速度を使用します。CSはGPIOで制御します。**PA5はSDのクロック用**であり、汎用LED出力として使わないでください。

カードの自動フォーマットは行いません。現在のファイルシステム設定では、GPT形式のパーティションテーブルには対応していません。カード容量や形式だけで全製品との互換性を保証するものではありません。

## 配線・書き込み時の確認

電源を切った状態で配線し、電源系統と共通GNDを確認します。特にマイク・microSDの信号は3.3 V系で接続します。配線は短く固定し、接触が不安定にならないようにします。

書き込みにはボード搭載ST-LINKを使用します。診断用シリアル出力はUSART2（PA2/TX、PA3/RX）、115200 bps、8 bit、パリティなし、1 stop bit、フロー制御なしです。

実装上のピン定義は [main.h](../Core/Inc/main.h)、周辺機能設定は [main.c](../Core/Src/main.c) と [MSP初期化](../Core/Src/stm32h5xx_hal_msp.c) にあります。次は[ビルドと書き込み](build.md)へ進んでください。
