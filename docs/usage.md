# 利用ガイド

[READMEに戻る](../README.md)

## 操作部

| 操作 | 用途 |
|---|---|
| ロータリーエンコーダを回す | 選択中の設定値を変更 |
| SW1（ボード搭載ユーザースイッチ） | 設定の決定、監視開始・停止、保存再試行 |
| SW2 | 時刻設定で「分」を選択 |

音声検出は自動です。SW2は時刻設定の「分の選択」にのみ使用し、監視中に押しても動作しません。

## 1. 起動と設定

[配線](hardware.md)と[プログラムの書き込み](build.md)を済ませ、microSDカードを挿入して電源を入れます。起動画面を約3秒表示した後、時刻設定へ進みます。

| 設定 | 操作 | 範囲・初期値 |
|---|---|---|
| 時刻 | エンコーダで「時」を変更し、SW2で「分」へ移動。分を変更してSW1で確定 | 00:00〜23:59、初期値23:59 |
| Delay | エンコーダで開始までの待ち時間を変更し、SW1で確定 | 0〜99分、初期値0分 |
| Gain | エンコーダでマイク入力の増幅量を変更し、SW1で確定 | ＋0〜＋48 dB、6 dB刻み、初期値＋18 dB |

時刻画面のSW2は「時」から「分」への移動です。時と分を交互に切り替える操作ではありません。設定値は上下限で循環します。

### 時刻設定：イベントの発生時刻の基準

**現在の時刻に合わせて設定します。** SW1で確定した時刻を基準に、その後の経過時間を加えて、いびき・咳などのイベントが発生した時刻を算出します。この時刻がmicroSDに保存するCSVの `time` 列に使われます。

例えば23:00に時刻を合わせて確定し、30分後にイベントが発生すると、記録上の時刻は23:30になります。設定後の操作時間やDelayの待ち時間も経過時間に含まれるため、監視開始時に時計が設定値へ戻ることはありません。

インターネットなどによる自動時刻合わせは行わないため、起動時に時計やスマートフォンを見て設定してください。

### DELAY設定：眠りにつくまで音声取得を待つ時間

**監視の開始操作後、実際に音声取得を始めるまでの待ち時間を設定します。** 設定範囲は0〜99分、初期値は0分です。

スイッチを押した直後から眠りにつくまでには、寝具を整える音、移動する音、会話などが発生します。その間は音声取得を行わないようにすることで、就寝準備中の生活音による誤検出を避けるための設定です。自分が眠りにつくまでの時間を目安に指定します。

例えば20分に設定すると、SW1による開始操作後、`Good Night` を約3秒表示してから20分待ち、その後に音声取得を開始します。0分の場合は、`Good Night` の表示終了後に音声取得を開始します。

### ゲイン設定：マイクから取得した音の増幅量

**マイク入力の音声を、どの程度増幅して処理するかを設定します。** 設定範囲は**＋0〜＋48 dB、6 dB刻み**で、初期値は**＋18 dB**です。

この設定は、マイクから取得したデジタル音声の振幅をソフトウェアで増幅するものです。＋0 dBは増幅なしで、6 dB上げるごとに振幅を約2倍として扱います。現実装では＋18 dBが8倍、＋48 dBが256倍に相当します。

マイクから離れていて音が小さい場合などに、入力音声の大きさを調整するために使います。ゲインを上げると、いびき・咳だけでなく周囲の雑音も増幅されます。また、上げすぎると音声が扱える数値範囲を超え、波形が頭打ちになってひずむため、値を大きくすれば必ず検出しやすくなるわけではありません。まずは初期値の＋18 dBを基準に、設置位置や入力音の大きさに合わせて調整してください。

各設定は電源再投入時に初期値へ戻ります。

## 2. 監視を始める

`Please press` / `ENTER key` の開始待ち画面でSW1を押します。`Good Night` を約3秒表示し、設定したDelayの終了後に音声取得を開始します。設定中とDelay中は音声取得を開始していません。

監視開始直後の有効音声2秒分は、周囲の音量の基準を作るために使います。この初期化中は自動推論を行わないため、最初は周囲を静かにして待ってください。

Delay中は設定した待ち時間が表示されます。現実装は毎秒のカウントダウン更新や、待機中のSW1によるキャンセルを行いません。

## 3. 監視中の表示

上段に `Monitoring`、下段にイベント数や `TRIG`、`SNORE`、`COUGH` を表示します。SNOREは「いびき」、COUGHは「咳」の分類結果です。OTHERはイベントとして保存しません。

表示件数は推論結果の記録通知に基づくため、RAM保存上限到達後などではCSVのイベント行数と一致しない場合があります。

## 4. 停止して保存する

監視中にSW1を押します。停止操作の時刻を記録し、`Good Morning` を約3秒表示して、音声処理・推論・記録の完了を待ちます。その後、microSDへの保存画面へ進みます。

保存完了画面を約3秒表示すると、開始待ち画面に戻ります。同じ設定で再度SW1を押すと、新しいセッションを開始できます。

**保存完了を確認してから電源を切り、カードを取り出してください。** 監視中の記録はRAMにあるため、保存前に電源を切ったりリセットしたりすると失われます。

## 5. CSVを確認する

microSDカードをPCへ接続し、ルートにある `EVT00001.CSV` などを開きます。以下は書式を示す例です。

```csv
time,event,value
23:59,START,
23:59,SNORE,184
00:01,COUGH,119
00:02,STOP,
```

`value` は0〜255の分類スコアで、音量や回数ではありません。おおよそのモデル出力値は `value / 256` で求められます。列の意味、日付をまたぐ場合、記録上限については[保存形式](data-handling.md)を参照してください。

## 保存に失敗したとき

保存失敗画面では、同じセッションの記録をRAMに保持します。カードの挿入状態を確認し、SW1で保存を再試行できます。通電中に配線を変更しないでください。配線の修正に電源断が必要な場合、未保存のRAM記録は保持できません。

| 状況 | 確認事項 |
|---|---|
| LCDが表示されず起動が進まない | LCD電源、I2C配線、レベル変換、アドレス、コントラスト |
| 音を入力しても記録されない | 初期化2秒の経過、マイク配線、ゲイン、OTHERへの分類の可能性 |
| 保存失敗が続く | カードの接続・空き容量・対応形式、SPI配線、シリアル診断ログ |
| CSVの時刻が合わない | 起動後の時刻設定。ファイル更新日時はイベント時刻とは連動しない |

シリアル接続条件は[ハードウェア資料](hardware.md)に記載しています。
